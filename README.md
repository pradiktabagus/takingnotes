> [!TIP]- 📜 Rules of Engagement (SOP Vault)
> *Klik untuk membuka/menutup aturan main vault ini:*
> 
> 1. **Zero Friction Input:** Jangan pusing memilih folder pas lagi sibuk. Semua catatan baru wajib masuk ke `00_Inbox` dulu.
> 2. **Max 1 Subfolder:** Di dalam `02_Wiki`, hanya boleh ada subfolder 1 tingkat (`Engineering`, `Athletics`, `Knowledge`). Jangan bikin sub-subfolder lagi!
> 3. **Atomic & Searchable:** Buat catatan wiki sespesifik mungkin (satu topik per file) dan hubungkan menggunakan `[[Link Note]]`.
> 4. **Definition of Done (Projects):** Begitu project di `03_Projects` selesai, saring kodingan/insight pentingnya ke `02_Wiki`, lalu hapus/arsip filenya.
